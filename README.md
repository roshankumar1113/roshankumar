# Roshan Kumar — Portfolio

Static site: index.html + style.css + script.js + assets/.

Run: open index.html in a browser (internet needed for GSAP, ScrollTrigger, Lucide icons and Google Fonts CDNs),
or serve locally: `python3 -m http.server 8000` then open http://localhost:8000

Edit: text in index.html, styling in style.css, animations in script.js.
Replace assets/photo.jpg and assets/certificate.jpg to change images.
